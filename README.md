# From Empire to Crisis: My HIST 213 Roadmap

A single-page, dependency-free HIST 213 roadmap by Diego Guevara, covering c. 1870 through the outbreak of World War II in 1939. The page uses plain HTML, CSS, and a small JavaScript file for the print button and navigation highlight. All content remains available without JavaScript.

## Run locally

Open `index.html` in a browser, or serve the repository root with `python -m http.server 8000` and visit `http://localhost:8000`.

## GitHub Pages

The site is ready to serve from the repository root. In the repository's **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. The expected address is `https://dlg309.github.io/HIST-213-Build-Your-Own-Roadmap-Webpage/`. Pages publication is not enabled by this repository change alone.

## Content and source notes

The Word draft supplies the introduction, arguments, earlier/current thinking, turning-point paragraphs, and 284-word reflection. Supplied HIST 213 slides support the added settlement and 1930s developments. `CONTENT_GAPS.md` records source identifiers that still need confirmation; no citation was invented to fill them.
